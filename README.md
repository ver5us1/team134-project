## 📌 О проекте

Точное прогнозирование цен на **AFRR capacity маркете** электроэнергии **Day-Ahead** позволяет участникам рынка принимать более эффективные торговые решения и снижать финансовые риски.

В рамках проекта мы разрабатываем и сравниваем модели машинного и глубокого обучения для прогнозирования цен на следующие сутки на основе исторических рыночных данных и внешних факторов. Финальный результат — **сервис на FastAPI**, который принимает данные и возвращает прогноз цены.

## 🗄 База данных

Проект использует **PostgreSQL 16**, развернутый на отдельном удаленном сервере. Доступ к базе имеют все участники команды.

**Параметры подключения:**
- **Host:** `***.***.***.***`
- **Port:** `5432`
- **Database:** `team134_db`
- **User:** `team134_user`
- **Таблица с данными:** `afrr_prices`

### 🚀 Как подключиться (для участников команды)

1. **Скопируйте шаблон окружения:**
   ```bash
   cp .env.example .env
   ```
2. **Откройте файл `.env` и впишите реальные данные** (IP-адрес сервера и пароль запросите у капитана команды в личных сообщениях).
3. **Установите/синхронизируйте зависимости:**
   ```bash
   uv sync
   ```
4. **Запустите проверочный скрипт:**
   ```bash
   uv run python -m src.data.test_connection
   ```

### 🧪 Проверочный скрипт

Для быстрой диагностики проблем с базой данных в проекте предусмотрен специальный скрипт — `src/data/test_connection.py`. 

Он автоматически:
- Проверяет, создан ли файл `.env`.
- Проверяет, заполнены ли все необходимые переменные (хост, порт, логин, пароль).
- Пытается подключиться к серверу и проверить наличие таблицы `afrr_prices`.
- Выводит количество строк и среднюю цену, подтверждая, что данные на месте.
- Если что-то не так — **пишет понятную инструкцию**, что именно нужно исправить (например, «Неверный пароль» или «Файл .env не найден»).

**Ожидаемый результат успешного запуска:**
```text
🔍 Проверка подключения к базе данных...

✅ УСПЕХ! Подключение установлено.
📊 Таблица 'afrr_prices' найдена.
📈 Количество строк: 26304
💰 Средняя цена (target_vwap_up): 23.44 €/МВт·ч

🎉 Всё готово к работе!
```

> ⚠️ **Безопасность:** файл `.env` содержит конфиденциальные данные и добавлен в `.gitignore`. Никогда не коммитьте его в репозиторий. В репозитории хранится только безопасный шаблон `.env.example`.

## 🧠 Подход и модели

### ML-этап (baseline)
| Модель | Назначение |
|--------|-----------|
| Linear Regression | Базовая линейная модель, benchmark |
| Random Forest | Устойчивая к выбросам ансамблевая модель |
| CatBoost | Градиентный бустинг с категориальными признаками |
| XGBoost | Классический градиентный бустинг |
| LightGBM | Быстрый бустинг для больших данных |

### DL-этап
| Модель | Особенность |
|--------|-------------|
| LSTM | Учёт долгосрочных зависимостей во временных рядах |
| TCN (Temporal Convolutional Networks) | Параллельная обработка временных окон |
| Transformers для временных рядов | Attention-механизм для долгих зависимостей |

### 🔬 Дополнительные направления
- Прогнозирование **ценовых скачков** (spikes)
- **Вероятностное** прогнозирование (интервальные оценки)
- Использование **погодных данных** и прогнозов генерации **ВИЭ**
